# 알바 통합검색

알바 탭은 POST /api/part-time-search/pages를 사용합니다. criteria.keyword(최대20자), criteria.regionIds(시도 또는 시군구1개 또는 전국), albamonPage/albaheavenPage(1부터 시작, null은 건너뛰기)를 받습니다. 사이트별 성공/실패와 nextPage를 따로 유지하며 실패 시 같은 페이지를 재시도합니다. 원문 HTML을 파싱하며 고유번호로 중복을 제거합니다. 급여는 원문 단위로 표시합니다. 원문 클릭은 기존 브라우저 읽음 기록을 사용합니다.

방문/검색/공고 클릭은 기존 usage_events의 part_time 분류로 기록됩니다. 관리자 화면의 알바 집계와 검색기록에 포함됩니다. search_events의 잡코리아/사람인 컬럼은 알바 결과 개수로 재사용하지 않습니다. 따라서 알바 검색 이력의 결과 개수는 별도 검색결과 기록을 추가하기 전까지 미집계입니다.

시군구는 기존 지역 목록으로 지원합니다. 알바몬에는 해당 지역코드, 알바천국에는 시도코드와 시군구 명칭을 전달합니다. 시도를 바꾸면 이전 시군구 선택을 초기화합니다. 시군구가 없는 지역은 전체로 검색합니다. 근무기간/요일/급여 조건은 아직 지원하지 않으며 필터에 표시하지 않습니다. 검색종류를 바꾸면 입력 및 현재 결과가 초기화됩니다. 읽음 기록은 유지됩니다. 서버의 페이지당 결과 개수와 유료 노출은 원본 사이트에 따라 다를 수 있습니다. 사이트 구조 변경이나 제한은 FAILED로 표시하고 0건으로 감추지 않습니다.

검증: Render에서 실제 공개 페이지의 검색/지역/다음페이지 반환 확인. PartTimeSearchServiceTest는 파서/입력검증, Render 빌드에서는 실제 서버 통합조회도 실행합니다. PC 브라우저는 테스트에 사용하지 않습니다.
