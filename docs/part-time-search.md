# 알바 통합검색

알바 탭은 POST /api/part-time-search/pages를 사용합니다. criteria.keyword(최대20자), criteria.regionIds(시도 또는 시군구1개 또는 전국), 선택적인 criteria.neighborhoodId(알바몬 읍면동 코드), albamonPage/albaheavenPage(1부터 시작, null은 건너뛰기)를 받습니다. 검색어 또는 지역 중 하나는 필수입니다. 지역을 선택하면 검색어는 빈 문자열·공백·생략 모두 허용하며, 둘 다 없는 검색은 화면과 서버에서 차단합니다. 채용 검색은 계속 검색어가 필수입니다. 사이트별 성공/실패와 nextPage를 따로 유지하며 실패 시 같은 페이지를 재시도합니다. 고유번호로 중복을 제거하고 급여는 원문 단위로 표시합니다. 원문 클릭은 기존 브라우저 읽음 기록을 사용합니다.

방문/검색/공고 클릭은 기존 usage_events의 part_time 분류로 기록됩니다. 관리자 화면의 알바 집계와 검색기록에 포함됩니다. search_events의 잡코리아/사람인 컬럼은 알바 결과 개수로 재사용하지 않습니다. 따라서 알바 검색 이력의 결과 개수는 별도 검색결과 기록을 추가하기 전까지 미집계입니다.

시군구는 기존 지역 목록으로 지원합니다. GET /api/part-time-search/neighborhoods?regionId=I000_I010 으로 해당 시군구의 읍면동 목록을 조회합니다. 알바몬의 공개 코드 API(`/codes/areas/korean/dongs/gucode?code=I010`) 응답을 검증해 24시간 메모리 캐시합니다. 시군구가 없는 세종은 시도 선택 후 조회합니다. 다른 시도 전체에서는 시군구를 먼저 선택해야 합니다. 목록 조회 실패는 503과 재시도 UI로 알리고, 실패 응답은 캐시하지 않습니다. 시도·시군구를 바꾸면 읍면동 선택을 초기화하며, 이전 목록 요청이 늦게 완료되어도 새 선택을 덮어쓰지 않습니다. 서버도 읍면동이 선택된 시군구에 실제로 속하는지 확인하고, 잘못된 조건을 넓은 지역으로 대체하지 않습니다.

알바몬에는 읍면동 고유 코드를 `areas`로 전달합니다. 검색어가 비어 있으면 `/total-search` 대신 실제 지역 검색 페이지 `/jobs/area`를 사용하고, 해당 페이지의 `__NEXT_DATA__` 중 일반 공고와 페이지 정보를 읽습니다. 2026-11-07 공개 페이지에서 강남구·개포동 지역 조건과 검색어 없는 결과를 확인했습니다. 원본 제목·업체·근무지역·급여·등록일·마감일을 유지합니다.

알바천국은 읍면동을 선택하거나 검색어 없이 지역만 조회할 때 실제 `/job/area/mainlocal` 검색을 사용합니다. 2026-11-07 사용자가 직접 검색해서 제공한 **경기 구리시 인창동** URL에서 다음 요청 필드를 확인했습니다.

- `schnm=LOCAL`, `viewtype=L`, `sidocd=031`
- `strAreaMulti=031||구리시||인창동`, `selGugun=구리시`, `selDong=인창동`
- `hidListView=LIST`, `hidSortCnt=50`, `hidSortFilter=Y`, `hidSearchyn=Y`, `page=1`
- 검색어 없는 원본 요청에는 `schIncludeText`도 빈 값입니다. 검색어를 넣으면 별도의 `schIncludeText` 조건으로 보내며, 지역 이름을 검색어에 섞지 않습니다.

**표시 주소를 검사해 공고를 제외하는 로직은 제거했습니다.** 원본 검색이 반환한 공고는 표시 주소가 시군구까지만 있거나 비어 있어도 유지합니다. 응답의 `input[name=strAreaMulti]`가 요청 지역과 일치하는지 검사하고, 다르거나 확인할 수 없으면 FAILED로 처리합니다. 지역이 넓어진 응답을 정상 결과로 표시하지 않습니다. 일반 채용정보의 테이블(`#NormalInfo`)과 목록(`#jobNormal`)을 읽고 원본 전체 건수를 유지하며, 해당 원본 요청의 페이지 크기 50으로 다음 페이지를 계산합니다. 검색어만 있고 읍면동 조건이 없는 기존 통합검색은 기존 페이지 크기 20을 유지합니다.

검증 한계: 요청 필드는 사용자가 실제 검색한 URL로 확인했습니다. 이 클라우드에서 해당 URL과 원본 스크립트의 직접 요청은 503·연결 시간 초과로 실패했습니다. 따라서 알바천국 실제 HTML/공고 ID/건수와 AllEZ 결과의 일치 및 페이지 연속성은 **아직 실응답으로 검증하지 못했습니다**. 테스트의 알바천국 응답은 회귀 검증용 고정 데이터이며 실제 인창동 HTML 캡처라고 간주하면 안 됩니다. 운영 병합 전에 실제 원본 응답과 대조해야 합니다.

근무기간/요일/급여 조건은 아직 지원하지 않으며 필터에 표시하지 않습니다. 검색종류를 바꾸면 입력 및 현재 결과가 초기화됩니다. 읽음 기록은 유지됩니다. 서버의 페이지당 결과 개수와 유료 노출은 원본 사이트에 따라 다를 수 있습니다. 사이트 구조 변경이나 제한은 FAILED로 표시하고 0건으로 감추지 않습니다. 지역만 검색해도 방문 통계의 search_click을 기록하며, 읍면동 코드는 기존 search_criteria JSON의 neighborhood_id에 보관합니다. DB 스키마 변경은 없습니다.

검증: PartTimeSearchServiceTest는 기존 파서/입력검증을 확인하고 Render 빌드에서는 실제 서버 통합조회도 실행합니다. PartTimeNeighborhoodsTest와 PartTimeNeighborhoodHttpTest는 고정 원본 응답으로 빈 검색어 허용, 둘 다 없는 검색 거절, 읍면동 소속 검증, 목록 캐시·재시도, 사용자가 제공한 원본 검색 조건, 주소가 생략된 공고 유지, 지역 조건 불일치 차단, 페이지 크기 및 HTTP 요청/응답을 검증합니다. 프런트 입력 검증 테스트와 데스크톱·모바일 브라우저 검증은 원본 사이트 응답을 대체하므로 실제 양쪽 사이트의 전체 동작을 보장하지 않습니다.
